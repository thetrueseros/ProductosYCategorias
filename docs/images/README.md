# Capturas para el README

Guardar aquí las imágenes con estos nombres. El README principal ya las referencia con rutas relativas.

| Archivo | Página | Qué debe mostrar |
|---|---|---|
| `dashboard.png` | `/` | Métricas, alerta de stock, últimos productos y productos por categoría |
| `products-index.png` | `/Products` | Filtros, tabla con precios en COP, badges de stock y paginación |
| `product-create.png` | `/Products/Create` | Formulario de alta con una categoría seleccionada |
| `categories-index.png` | `/Categories` | Las cinco categorías con su número de productos |
| `category-delete-blocked.png` | `/Categories/Delete/1` | Aviso que impide eliminar una categoría con productos |

Especificaciones:

- Formato PNG.
- Ventana de 1440 px de ancho y zoom al 100 %.
- Tema claro.
- Datos del seed, sin información personal.
- Mismo ancho en todas las capturas.

Opcionales, no referenciadas en el README para no dejar imágenes rotas:

- `product-details.png`: `/Products/Details/1`.
- `error-404.png`: cualquier ruta inexistente.
